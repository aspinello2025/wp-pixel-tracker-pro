# WP Pixel & Tracking Pro

Gerenciador profissional de pixels e rastreamento para **WordPress** e **WooCommerce**.

## Recursos Principais
- **Meta Conversions API (CAPI Server-Side):** Envio direto de eventos do servidor para máxima precisão de conversões.
- **Múltiplos Pixels:** Configure múltiplos pixels para Meta (Facebook/Instagram), Google Analytics 4 (GA4), TikTok Ads e Google Ads.
- **Rastreador & Gerador de UTMs:** Capture e armazene parâmetros de campanha nos pedidos WooCommerce.
- **Módulo Super Pack:** Desativação de pixels por página, páginas de agradecimento customizadas e suporte a WPML.
- **Atualização Automática no WordPress:** Notificações e atualizações diretas com 1 clique no painel do WordPress através deste repositório GitHub.

## Instalação
1. Baixe o pacote mais recente: [`wp-pixel-tracker-pro.zip`](https://raw.githubusercontent.com/aspinello2025/wp-pixel-tracker-pro/main/wp-pixel-tracker-pro.zip).
2. No seu painel WordPress, acesse **Plugins > Adicionar Novo > Enviar Plugin**.
3. Selecione o arquivo `wp-pixel-tracker-pro.zip` e clique em **Instalar Agora**.
4. Clique em **Ativar Plugin**.
5. Acesse **WP Pixel & Tracking > Licença** para ativar sua chave de licença.
